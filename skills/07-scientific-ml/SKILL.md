# 科学机器学习与粒子仿真

## 适用情形与输入

用于粒子动力学、神经求解器、物理闭合、混合仿真或学习型数值算法研究。输入为任务物理、离散方法、部署可见信息、参考数据、目标精度与资源预算。监督、自监督和强化学习依据信号可识别性选择。

## 1. 定义物理、离散与学习对象

分别说明连续物理、数值近似和网络负责什么。区分物质粒子、采样粒子、示踪粒子和粗化质量包；写明质量、体积、速度、材料或内部状态，以及从状态到观测物理量的读出。

给出边界、物性、尺度、时间步、预测区间和使用者关心的量。记录部署是否能一次读取细状态、拥有历史、查询几何或周期性调用参考求解器。任何额外信息与调用成本都属于方法的一部分。

## 2. 将长期失败拆成可测来源

分别考虑输入不充分、表示损失、微分或传输误差、时间积分、未收敛残差、训练覆盖和自身状态漂移。粒子分布的聚集、空洞、覆盖方向和邻域变化可以改变离散质量，应与动力学误差分别测量。

信息不足主张需匹配模型全部实际输入，再检查未来是否不同。理想谱截断的反例只适用于声明的粗化，需在实际粒子表示上验证。主张学习算子能改进时，先用高成本逐实例优化检查收益空间；主张强化学习调度有价值时，先比较短视与长视动作选择。

低幅值模式与高频模式是不同属性。分析训练误差时按幅值、频率和方向分别测量，检查低幅值误差能否经非线性相互作用影响长期结果。

## 3. 按信息与计算设计表示

关键守恒量、边界条件和需要精确控制的状态可显式保留，其余信息在固定预算下编码。比较同维度的手工统计和学习表示；使用内部状态时，验证它在参考答案离开后能否自主推进。

多个局部查询共享几何或全局上下文时，分开昂贵编码与按需读出，记录复用成本。动态计算根据当前误差或信息需求分配资源，保留必要验收与回退机制，并与传统自适应方法比较。

## 4. 核查数值接口

写清量纲、质量／体积、压力自由度、离散矩阵性质、邻域及边界处理。学习系数时检查零阶和高阶矩、正性要求、两个方向的兼容性，以及实际分母、约束层与局部求解器的梯度。

为粒子跨格、邻居切换、边界截断、退化点云、可变质量和分辨率安排单元测试。区分硬结构保证、损失促进和经验结果。局部传输性质不能自动证明完整时间推进稳定；修改核或系数后，应核对力、梯度和状态更新所用接口。

## 5. 构造可识别且符合物理条件的数据

用受控剪切、拉伸、边界变化或物理干预检验假设，联合保持所声明的不变量。改变初值或物性后重新取得参考演化；区分解析场标签、有限精度数值轨迹和真实实验观测。

先保证数据含有目标机制，再扩大覆盖。既训练正确状态附近，也按部署方式训练自身状态中的后续演化，避免长期预测每一步隐含读取参考输入。

按场景、轨迹、母初值、物性区域和干预家族分组切分。参考解误差与评价分辨率需足以识别方法差异；必要时进行参考求解器的时空收敛检查。

## 6. 独立评价物理与计算收益

分别测表示误差、单步误差、求解残差、自主长期演化和最终任务量。对混沌流动区分有限时间预测与长期统计；结合能谱、输运、受力、密度或散度等与任务相关的量。独立评价算子与读出，避免由模型自己的残差定义其正确性。

比较优化后的传统方法、同状态预算的固定特征、同架构不同目标、同数据不同架构，以及适度提高分辨率的传统方案。真值状态或精确子解只作为定位瓶颈的参考。

保持物理时间、误差要求、硬件和可用信息可比。计入数据、训练、初始化、建图、推理、约束、校正、回退与内存。将粒子数量增加、同物理域的分辨率变化与收敛性分别评价。

## 输出与验收

形成任务及部署说明、机制诊断、数值接口、数据与参考误差、物理评测、精度—成本曲线和下一决策。理想构造、单元检查、真实流体结果分别标记。

通过条件是所测机制与真实粒子接口相符，数据可识别目标，独立物理结果支持声明的收益，并且成本适合目标应用。有效贡献可以是精度、鲁棒性、新能力或加速，选择由证据决定。
