# 研究决策与写作

## 适用情形与输入

用于阶段评审、方案冻结、论文写作、审稿回复和经验沉淀。输入为当前问题、最近邻、实际结果、资源与未决假设。

## 1. 根据结果决定下一步

综合价值、剩余不确定性、可检验性和成本，选最可能改变结论的动作。机制成立但模型无效时调整设计；方法有效但解释不足时补机制实验或降低解释强度；收益由数据或训练解释时将贡献归于相应部分。

简单方法已经解决目标问题时，选择仍有实际价值的边界或结束该主张。结果不显著时同时核查实现、误差尺度和统计能力。规模化前确认增长趋势和资源曲线；理论工作定位尚未闭合的假设或证明；数据工作确认效度、标注和污染。

## 2. 确定一条有证据的主线

用一句话陈述核心发现，再组织“重要问题—关键判断—设计—证据”。优先解释真正改变认识或实践的部分，其他贡献围绕主线展开。

相关工作按已有能力、信息接口、机制和验证范围比较。采用的数学工具、数据与模块在论文中准确引用。新的组合要说明由问题产生的必要联系及额外能力；改名称、换领域或增加组件本身不构成这种论证。

## 3. 独立撰写研究方案与论文

研究方案包含问题与价值、最近邻与差异、关键假设、架构和训练接口、数据与评测、最小验证和预算。论文内容由实际结果决定，计划和预期不能充当结果。

摘要直接从当前对象、目标和发现开始；方法标题使用实际模块或学习任务；实验先展示裁决核心主张的结果，再展开机制、范围与效率。每张图表对应一个问题，正文说明读者应从中获得什么判断。

任务条件放在任务定义，理论条件放在定理或分析，经验范围放在实验与讨论。选题变更、会话纠错和行动日志保存在工作记录，正式文本完整说明当前研究。

## 4. 匹配表达与证据强度

分别标记文献报告、推导、已执行测试、计划与假设。理论给出假设与量词，实验给出数据、规模、预算和不确定性。检索没有发现同款时说明检索范围；应用外推需要对应验证。

审查每项结论的最强反对解释、对照公平性和未解决部分。会议与奖项提供研究语境，录用概率不代替技术判断。

## 5. 沉淀可迁移能力

每次保留少量真正改变决策的经验，写成“适用条件—判断依据—具体操作—通过标准—边界／反例”。正文直接解释方法，使后续 agent 无需先找某个案例才知道如何执行。

具体技术事实、文献归属和实验证据仍保存在项目记录中。更新通用规则时核查反例和适用范围，既不丢失来源，也不把来源编号当作知识本身。

## 输出与验收

阶段报告写明当前发现、最重要的未决问题、继续／修改／扩展／暂停的理由，以及下一实验的预算。可选用[评审模板](../../templates/research_review.md)。

交付前检查：研究对象是否清楚，方法与假设是否对应，结果是否真实执行，贡献归属是否准确，以及每个段落是否提供问题、设计、实现或验证信息。
